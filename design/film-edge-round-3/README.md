# Film Edge — round 3

Refines round 2 B following Connor's annotated reference.

- Front blade narrowed by approximately 30% at both ends, preserving the inner edge and shared lower tip. It remains thicker than the rear blade.
- Restored roughly 12-unit transparent space along the film's left edge and above/below the ribbon where it crosses the rear blade.
- Rear blade is continuous behind the front blade; the front overlaps it at the tip.
- Four film colors on otherwise identical geometry: A white (#F3F6F4), B original teal (#04635F), C cool silver (#B9C9CD), D ivory (#EDE6D8).
- Blade colors stay #71D7CD front / #489F96 rear for a fair color comparison.

All individual logos are transparent SVG vector geometry with transparent perforations and gaps. The mask uses vector paths, not a painted background, so the spaces work on any surface. A single-color SVG and isolated V construction are included.
