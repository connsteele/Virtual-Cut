# Virtual Cut logo studies

Four original vector concepts based on Connor's V/scissors and notched-film sketch. These are candidates for review, not an approved replacement for the app logo.

Open index.html for the gallery, or virtual-cut-logo-studies.svg for the comparison board.

- 01 Splice: closest to the supplied silhouette.
- 02 Film edge: perforations strengthen the film reference.
- 03 Open C: wider cut opening makes the C more legible.
- 04 Cutline: an outlined film strip balances the solid V.

Each has dark, light, and mono SVG versions. All individual marks contain only vector paths with true transparency, no raster image or font dependency. The mono version inherits currentColor when embedded inline and defaults to #04635F as a standalone file. Dark versions pair #04635F film with #71D7CD blades; light versions use #04635F blades and #39968E film. Small details in Film edge may need a simplified variant if selected for tiny icons.

The comparison board and HTML gallery use live text for labels. No logo direction has been applied to the application yet.
